# 隔离标准模板发布权限

平台运维需要更新标准模板的镜像，而普通 Agent 配置属于 Owner。选择独立的同模板发布
操作及用途绑定授权，复用现有配置事务、镜像准入、审计、幂等和 Worker 调谐；完整规则
只在 [工程 Spec 第 10.4 节](../architecture/SPEC-agent-infra-M1-engineering-architecture.md#104-模板与自定义镜像升级)
维护。

该选择让经部署授权的管理员更新指定模板镜像，同时保留普通配置的 Owner 边界。代价是
部署需提供精确发布目标和当前运维资格；不把管理员角色扩展为所有模型、Secret、渠道及
Owner 配置的写权限，也不让部署脚本通过伪造 Owner 或绕过生产授权来使用配置事务。
