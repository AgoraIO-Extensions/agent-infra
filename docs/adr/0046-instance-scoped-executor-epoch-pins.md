# ADR-0046：按已授权 executor 实例固定持久 epoch

- 状态：Proposed（随 #4274 工程合同评审）
- 日期：2026-11-20

## 背景与决定

现有 binding 级 epoch pin 保护原实例未决工作，却把同 binding 下已获准的新 Pod 也判为替换冲突。
仅更新启动投影名和期限不能消除该冲突。沿用已批准的独立 executor 与按实例启动意图，
采用由 Store 提交和签名启动身份共同授权的实例级持久 pin；既有记录保留原归属。

完整授权、记录与兼容规则由
[Runtime HLD §10.3.1](../architecture/HLD-agent-runtime-M1.md#1031-排空通道的实例身份交付)
统一定义，工程 Spec 引用该节。该决定不改变 PRD 的会话、授权或历史保留要求。

## 取舍与后果

- 相比直接替换 binding 级 pin，分开记录新实例不会覆盖旧事实；相比只信任启动引用字符串，
  授权由既有 Store、部署信任根和本地实例核对共同承担。
- 代价是保留历史实例索引，处理旧格式与版本化采用，并在回退前保持兼容消费者。
  证据不完整时可用性让位于原事实保护，不能用新实例掩盖未知副作用。
- 保持现有部署单元、身份材料保护和控制通道；不增加 Pod 结构、权限、资源、进程命名空间
  或 env 名，不引入上游补丁。代码、部署与 ACK 验收仍须分别交付，文档合入不解除 #4274 门禁。
