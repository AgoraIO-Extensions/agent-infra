# ADR-0042：为指定自定义 Agent 选择固定域名路径入口

## 状态

负责人已确认实施方向；代码评审和真实环境验收由
[#4095](https://github.com/AgoraIO-Extensions/agent-infra/issues/4095) 收口。

## 背景

部署的 DNS 管理规则可能不允许通配解析，而自定义 Agent 仍需独立可发布的访问链接。
逐个申请域名会让每个 Agent 的发布依赖一次 DNS 操作。现有地址模型只支持 origin，
不能表示同一固定域名下不同的路径。

## 决策

为自有身份入口增加部署可选的路径发布方式，沿用既有身份、镜像准入、生命周期和
已验证运行状态，不新增镜像审批。地址、信任范围、应用适配及发布校验的完整规则统一见
[工程 Spec §14.3](../architecture/SPEC-agent-infra-M1-engineering-architecture.md#143-自有交互入口)。

## 影响

SRE 只需交付一个精确域名及其证书，部署选择 Agent 后由 Worker 发布路径。
应用必须支持子路径；不同路径不会获得独立的浏览器 origin，因此该域名与平台管理页面
分离，且只承载同一信任范围内的应用。原独立 Host 和平台身份入口继续沿用原契约。

本决策不表示域名、证书或应用已经上线，实施和外部验收分别记录。
