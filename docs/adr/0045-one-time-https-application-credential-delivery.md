# ADR-0045：以一次性 HTTPS 响应交付应用凭证材料

- 状态：Proposed（随 #4264 工程合同评审）
- 日期：2026-11-20

## 背景与决定

[平台 PRD §7.3](../prd/PRD-agent-platform-M1.md#73-api-身份凭证与授权)已区分应用凭证管理权与独立材料授权。
现有生产交付入口只有进程内受控消费者接缝；缺少真实接收者时拒绝签发是正确行为，不能用 fixture、任意落盘或部署回调冒充接收。

采用[工程 Spec §9.2.1](../architecture/SPEC-agent-infra-M1-engineering-architecture.md#921-应用凭证材料的进程外一次性交付)的
一次性专用 HTTPS 接收响应。管理者先登记非秘密意图，接收者以自己的当前受信身份触发生成与直接交付；材料授权在各边界重新核实。
交付权威仍是现有 Platform Access Core/Store，协议适配仍在 Platform API，不增加服务、网络队列、平台材料存储或新身份。
完整时序、状态、故障和版本化规则仅由该 Spec 定义；本 ADR 不改变 PRD 授权语义或 Connection 凭据边界。

## 取舍与后果

- 专用响应允许真实进程外接收，管理者只有元数据。相比回调 URL，不引入调用方选择目标和 SSRF；相比文件、Secret 或下载对象，
  不产生可重读的材料副本；相比异步队列，不新增保管者和后台投递责任。
- 代价是接收者必须在有界期限内在线；原材料在崩溃后不可恢复。HTTP 写出、接收者确认与数据库提交无法组成跨网络原子事务，
  结果不明须保留原引用，不能通过重送或自动轮换掩盖。
- 新通道按版本化合同显式采用，旧同步接缝不被重新解释为生产进程外证明。回退先关闭新准入，保留兼容读方与在途未知元数据；
  后续恢复继续按原授权撤销或显式轮换，不恢复或重放原材料。

实现与 Helm 接线分别交付并独立评审；本文件不授权现场写入，生产能力只由真实接收者及独立 ACK 验收证明。
