C Connection 登录控制台

Codex MCP

将 Connection 安装到 Codex

通过一个受控入口使用 GitHub、Jira、Confluence 等外部服务。Connection 保管账号凭证，Codex 只获得你明确授权的 Action。

1

添加 MCP 服务

在本机终端执行：

codex mcp add connection --url https://agent-connector.la3.agoralab.co/mcp
2

登录 Connection

继续执行，随后在浏览器中完成公司账号登录：

codex mcp login connection --scopes mcp --oauth-client-registration dcr

安装不会自动授予外部账号权限

登录后，请在 Connection 控制台连接所需的 Provider，并明确批准 Codex 可以使用的账号和 Action。不要把 LDAP 密码、Connection Token 或 Provider Credential 粘贴到聊天或 Codex 配置中。

打开 Connection 控制台
